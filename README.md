[`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app)으로 초기 구성한 [Next.js](https://nextjs.org) 프로젝트입니다.

## 시작하기

먼저 개발 서버를 실행합니다.

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 결과를 확인합니다.

`app/page.tsx`를 수정해 페이지 편집을 시작할 수 있습니다. 파일을 편집하면 화면이 자동으로 갱신됩니다.

이 프로젝트는 [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts)로 Vercel의 글꼴 모음인 [Geist](https://vercel.com/font)를 자동 최적화하고 불러옵니다.
